# Дизайн-код Проксимы

Источник — дизайн-система сайта «Amber & Forest» (`website/DESIGN-SYSTEM.md`):
токены, шрифты, компоненты и правила берутся оттуда без переизобретения.
Логотип — эмблема сервиса ГЕОНЕКСА. Название продукта — **Проксима**,
глобальный сервис Геонексы.

Ниже — что переносится как есть, что адаптируется под админку и почему.

---

## 1. Что переносится, а что меняется

Сайт — это фильм: пины, камера, долли-галереи, прелоадер с набегающим
процентом. Админка — прибор, в который смотрят по сорок минут подряд. Материалы,
цвета, шрифты и компоненты переносятся дословно; кинематография — нет.

| Из системы сайта | В админке |
|---|---|
| Четыре материала: навь, крем, янтарь, лес | **как есть** |
| Один интерфейсный акцент (янтарь) | **как есть** — единственный цвет действия |
| Тёплые нейтрали, ни чистого белого, ни серых теней | **как есть** |
| Документность: моношрифт на реквизитах, табличные цифры, пунктирные строки | **как есть** и даже плотнее — это язык админки |
| Unbounded / Inter / JetBrains Mono | **как есть** |
| Пин, долли, параллакс, магнитные кнопки, курсор-кольцо | **убрано**: в рабочем инструменте движение мешает |
| Прелоадер с процентом | **убрано**: вход по JWT, а не занавес |
| Секции `clamp(90px,14vh,150px)` | **сжато** до 24–40px: экран показывает данные, а не дышит |
| Радиусы карточек 18–26px | **сжато** до 12–16px на плотных списках, 18–20px на панелях |
| Появления `y 34 → 0`, .6s | **сокращено** до .18s и только на смене раздела |

Правило простое: всё, что несёт смысл, остаётся; всё, что играет роль камеры,
уходит. Ховеры, статусные точки, пунктирные строки и янтарные числа — смысл.
Наклон карточек за курсором — камера.

## 2. Логотип и имя

```
[эмблема]  ПРОКСИМА
           ГЛОБАЛЬНЫЙ СЕРВИС ГЕОНЕКСА
```

- **Эмблема** — `static/brand/gx-emblem.svg` (тёмная штриховка, для бумаги) и
  `gx-emblem-inv.svg` (кремовая штриховка, для нави). Файлы отличаются только
  цветом штриховки нижнего слоя и контуров; `viewBox="-194 -24 388 426"`,
  пропорция 388×426. В шапке — высота 32px, на экране входа — 84px.
- **Имя** — Unbounded 800, `letter-spacing .06em`, как `.gx-name` на сайте.
- **Подпись** — JetBrains Mono 10.5px, UPPERCASE, `letter-spacing .24em`,
  цвет `--amber` на нави и `--amber-d` на бумаге, как `.gx-sub`.
- Эмблема и имя не переокрашиваются и не разносятся: это один блок с
  `gap 18px`, выровненный по центру.

Четыре цвета эмблемы — `#16181A`, `#C8281B`, `#E0A02E`, `#EFE8D8` — цвета знака,
а не палитра интерфейса. Красный `#C8281B` в интерфейсе живёт только в эмблеме
и в статусах ошибок; серией данных он не бывает (см. §5).

## 3. Токены

Копируются в `admin-ui/src/app.css` на `:root`. Первый блок — дословно из
`website/src/styles/global.css`, второй — добавления админки.

```css
:root{
  /* --- из дизайн-системы сайта, без изменений --- */
  --bg:#111826; --bg-2:#141B2A;
  --ink:#F4EFE4; --ink-dim:#C9C2B2; --muted:#948E80;
  --line:rgba(244,239,228,.13); --line-soft:rgba(244,239,228,.06);

  --paper:#F2ECDF; --paper-2:#E9E1CF; --paper-card:#FBF8F1;
  --ink-d:#221A0E; --ink-d-dim:rgba(34,26,14,.68); --mut-d:rgba(34,26,14,.52);
  --line-d:rgba(34,26,14,.16); --line-d-soft:rgba(34,26,14,.09);

  --amber:#E8A33D; --amber-hi:#FFC96B; --amber-d:#A66A14; --amber-deep:#8F5A10;
  --emerald:#5DB585; --emerald-hi:#A6D9BE; --emerald-d:#0A6E36;
  --emerald-rgb:93,181,133;

  --font-d:'Unbounded',system-ui,sans-serif;
  --font-s:'Inter',system-ui,sans-serif;
  --font-m:'JetBrains Mono',ui-monospace,monospace;

  --ease:cubic-bezier(.22,1,.36,1);

  /* --- добавления админки --- */
  --wrap:min(1600px,96vw);           /* шире сайтовых 1280: таблицы */
  --row:38px;                        /* высота строки таблицы */
  --gap:12px;
  --r-card:16px; --r-panel:20px; --r-field:10px; --r-pill:99px;
  --dur:.18s;                        /* вместо сайтовых .35-.6s */

  /* поверхности графиков: бумага-карточка и вторая навь */
  --viz-surface:#FBF8F1;
  --viz-grid:rgba(34,26,14,.10);
  --viz-axis:rgba(34,26,14,.22);

  /* серии данных — см. §5, значения провалидированы */
  --s1:#E8A33D; --s2:#0A6E36; --s3:#168EBF;
}

:root[data-theme="dark"]{
  --viz-surface:#141B2A;
  --viz-grid:rgba(244,239,228,.09);
  --viz-axis:rgba(244,239,228,.20);
  --s1:#C38316; --s2:#007839; --s3:#00729B;
}
```

Тёмная тема админки — это навь сайта; светлая — крем. Переключатель ставит
`data-theme` и побеждает системную настройку в обе стороны; тёмные значения
объявлены отдельно, а не выведены инверсией.

Производные константы (тени, свечения, скримы, зерно) берутся из раздела 2
дизайн-системы сайта без изменений, кроме теней покоя: в плотных списках
`0 1px 3px rgba(60,42,12,.05)` вместо `0 2px 10–16px`.

## 4. Типографика

| Роль | Шрифт | Где в админке |
|---|---|---|
| Дисплей | **Unbounded** 500–800 | имя сервиса, H1/H2 разделов, hero-числа KPI, крупные значения |
| Текст | **Inter** 300–600 | абзацы, названия в списках, кнопки, поля форм |
| Разметка | **JetBrains Mono** 400–500 | ярлыки, ID, cron, статусы, счётчики, оси и подписи графиков, значения в таблицах |

- **Eyebrow раздела** — mono 10–12px, UPPERCASE, `letter-spacing .4em`; цвет
  `--amber-d` на бумаге, `--amber` на нави.
- **H1 экрана** — Unbounded 800 `clamp(24px,2.4vw,34px)`, `line-height 1.05`.
  Сайтовые `clamp(...,104px)` в админке не нужны: заголовок не сцена.
- **Заголовок карточки/панели** — Unbounded 600 18–20px, `letter-spacing −.015em`.
- **Тело таблицы** — Inter 13px / 1.45; числовые колонки — mono 12.5px.
- **Все цифры системы табличные**: `font-variant-numeric: tabular-nums` на
  таблицах, осях, счётчиках и KPI. Это правило сайта, и в админке оно
  обязательнее: колонки должны выстраиваться.
- **Ранг-чип** — mono 10px в пилюле `1px currentColor`, `opacity .75`:
  «Геонекса · Проксима», «arXiv · 04».

Шрифты — локальные WOFF2 из `admin-ui/static/fonts/` (скопированы с сайта,
19 файлов, 304 КБ, с кириллическими сабсетами и `unicode-range`).
Предзагружаются три: Unbounded 800, Inter 400, JetBrains Mono 400.

## 5. Цвет данных

Здесь дизайн-система сайта заканчивается: у неё один интерфейсный акцент и один
драгоценный материал — этого хватает лендингу и не хватает графикам. Поэтому
серии данных выведены из фирменных тонов и **прогнаны валидатором**, а не
подобраны на глаз.

### Что выяснилось

Бренд тёплый: янтарь (H 73°) и красный эмблемы (H 30°) разнесены всего на 43°.
Как соседние слоты категориальной шкалы они проваливают порог различимости —
`ΔE 14.5` при норме 15 даже для полного цветовосприятия, и `ΔE 4.1` для
дейтераномалии на тёмной поверхности. Никакой подбор светлоты это не чинит:
тона слишком близки.

Отсюда решение, которое к тому же совпадает с правилом самой системы
(«янтарь — интерфейс», «статус — не серия»): **красный остаётся статусом и
эмблемой, серией он не бывает**. Категориальных слотов у бренда честно три —
янтарь, лес и выведенный из предметного голубого синий. Четвёртой серии нет:
девятый (и четвёртый) тон не генерируется, хвост сворачивается в «Прочее» или
разносится по малым множествам.

### Слоты

| Слот | Роль | Светлая `#FBF8F1` | Тёмная `#141B2A` |
|---|---|---|---|
| 1 | люди · принято · личный канал | `#E8A33D` — токен `--amber` как есть | `#C38316` |
| 2 | группы · отклонено · лес | `#0A6E36` — токен `--emerald-d` как есть | `#007839` |
| 3 | каналы · третья серия | `#168EBF` | `#00729B` |

В светлой теме слоты 1 и 2 — **буквально токены дизайн-системы**, `--amber` и
`--emerald-d`, без пересчёта. Синий выведен из предметного голубого сайта
(`#7CC7EE`, H 232°) сдвигом светлоты в полосу.

В тёмной теме шаги пересчитаны: сценический `--amber #E8A33D` имеет светлоту
0.765 при потолке полосы 0.67 — на графике он подавлял бы остальные серии. При
этом `--amber` остаётся интерфейсным акцентом тёмной темы (кнопки, активный
пункт, ярлыки) — просто не серией данных. Разделение ровно по букве системы:
янтарь-интерфейс и янтарь-данные это разные работы.

### Результаты валидатора

```
node scripts/validate_palette.js "<hex,…>" --mode <light|dark> --surface <hex> [--pairs all|--ordinal]
```

| Набор | Режим | Итог |
|---|---|---|
| Серии 1–3, `--pairs all` | светлый | PASS · CVD ΔE 19.9 · normal ΔE 20.9 · `#E8A33D` контраст 2.03 → нужны видимые подписи |
| Серии 1–3, `--pairs all` | тёмный | PASS · CVD ΔE 10.2 · normal ΔE 15.9 · контраст всех ≥ 3:1 |
| Ординал воронки (5 шагов) | светлый | PASS · монотонность, ΔL ≥ 0.06, светлый конец 2.06:1 |
| Ординал воронки (5 шагов) | тёмный | PASS · светлый конец 2.38:1 |
| Диверген: красное плечо | оба | PASS · один тон, ΔL ≥ 0.06 |
| Диверген: лесное плечо | оба | PASS · один тон, ΔL ≥ 0.06 |

Янтарь на бумаге даёт контраст 2.03:1 — это не брак, а **правило рельефа**:
там, где он несёт серию, обязательны видимые подписи значений или табличный
вид. Ровно та же оговорка есть у эталонной палитры.

### Ординальная шкала — воронка сбора

Один тон янтаря, светлота монотонна. Стадии упорядочены, порядок несёт смысл —
категориальную шкалу сюда ставить нельзя.

```
светлая:  #E1A44E  #C78B32  #AD720B  #8F5D00  #714900
тёмная:   #794E00  #936000  #AD720B  #C3882E  #DA9D47
```

### Диверген-шкала — фидбек

Красный ↔ лес, нейтраль серая. Тёплое против холодного, и это ровно та
семантика, что уже есть в системе: `#0A6E36` «действует», `#B33A3A` «истёк».

```
светлая:  #B83023  #D5867A  │ #E9E1CF │  #6DB07F  #09773B
тёмная:   #C13E2F  #DC8C80  │ #383835 │  #73B785  #167D40
          не интересно  ←   нейтраль   →   полезно · очень интересно
```

### Статусы — из системы сайта, не перекрашивать

```
действует / успех      #0A6E36
истекает / внимание    #A66A14  + пульс
истёк / ошибка         #B33A3A  (текст #9B2C2C)
в эфире                #41D97C  — только точка 6–7px с glow
Telegram               #7CC7EE  подложка rgba(42,171,238,.28→.06)
справочно / бессрочно   --mut-d @ .6
```

Статусный цвет всегда идёт с иконкой и подписью и никогда не становится
«серией 4». Точка статуса — 7px круг плюс `box-shadow 0 0 0 3–4px` того же
цвета `@.12`; «истекает» и «в очереди» пульсируют.

### Предметные цвета — неприкосновенны

Стратиграфия `#6F563C · #A26A35 · #DDB56A · #B9D4E4 · #8E9198 · #47836E`
применяется только там, где рисуется разрез или геологический слой. Как
категориальная шкала для абстрактных серий она не используется: половина
оттенков не проходит порог хромы и читается серым.

## 6. Виджеты

Компоненты берутся из раздела 6 дизайн-системы сайта. Ниже — только то, что
меняется или добавляется для админки.

**Кнопка primary** — пилюля, градиент `amber-hi → amber`, текст `#1D1302`,
свечение `0 10px 34px rgba(232,163,61,.3)`. В админке `padding 10px 20px`
вместо сайтовых `15px 28px`; заливка кремом при ховере остаётся, магнитный
сдвиг за курсором убран.

**Кнопка ghost и кнопка-иконка** — как в системе; иконка 30px, радиус 9px.

**Панель** — тёмная `linear-gradient(135deg,#151D2C,#0E141F 62%)` с янтарным
radial-wash в правом верхнем углу: шапка приложения и экран входа. Рабочие
экраны — на бумаге.

**Карточка** — `--paper-card`, радиус `--r-card`, рамка `--line-d-soft`, тень
покоя. Ховер только у кликабельных: подъём −2px (не −5px), янтарная рамка.

**Стат-плитка (леджер)** — сетка 4×1 или 2×2: число Unbounded 600
`clamp(22px,2.2vw,30px)` + подпись mono UPPERCASE 9.5px + дельта + спарклайн.
Цвет числа по роли: янтарь — метрика, чернила — количество, лес — «действует».

**Чип / тег** — mono 10–11px пилюля `1px --line-d`, `padding 6px 12px`.
Статусный чип — рамка и текст цветом статуса.

**Табы-фильтр** — mono 11.5px пилюли; активный — заливка `--ink-d`, текст
`--paper`, счётчик `<em>` янтарём.

**Таблица** — строка `--row` 38px, разделители `1px dashed --line-d-soft`
(пунктир из системы, он же язык бланка), ховер строки — янтарный wash
`rgba(232,163,61,.06)`. Заголовок колонки — mono 10px UPPERCASE `.12em`.
Числовые колонки — mono, табличные цифры, выключка вправо. Сортировка и
пагинация серверные. Липкая шапка и первая колонка.

**Строка на пунктире** — для реквизитов, параметров прогона, полей подписки:
`grid`, `padding 7px 0`, `border-bottom 1px dashed --line-d-soft`.

**Поле формы** — фон `--paper-card`, рамка `--line-d`, радиус `--r-field`,
`padding 9px 12px`, Inter 13.5px; фокус — рамка `--amber-d` и кольцо
`rgba(232,163,61,.18)`. Ошибка — рамка `#B33A3A` и подпись mono 11px.

**Модальное окно** — как в системе: карта `--paper`, радиус 24px, шапка на
`--paper-card` с eyebrow, H3 и действиями, закрытие 42px, Esc и клик по скриму,
возврат фокуса. Вход укорочен до `.22s`.

**Тултип графика** — `--paper-card` на бумаге и `#151D2C` на нави, рамка
`--line-d` / `--line`, радиус 10px, тень, mono 11px, табличные цифры;
заголовок — дата, строки — «цветная марка · подпись · значение».

**Пустое состояние** — пунктирная рамка, mono-подпись, одна primary-кнопка.

**Фокус** — `:focus-visible` кольцо `--amber` 2px с отступом 3px. Из системы,
менять нельзя.

## 7. Плотность и ритм

- Контейнер `--wrap: min(1600px,96vw)` — шире сайтовых 1280px, иначе таблицы
  доставок и решений сбора не помещаются.
- Отступ раздела 24–40px вместо сайтовых `clamp(90px,14vh,150px)`.
- Сетка карточек: 4 колонки ≥1440px, 3 до 1440, 2 до 1024, 1 до 680.
- Дашборд: KPI-строка 4×1, ниже графики 2×2, ниже лента ошибок на всю ширину.
- Контрольные точки наследуются с сайта: 1280, 1024, 900 (модалки
  полноэкранные), 680, 480.
- `html{overflow-x:clip}` — горизонтального скролла нет; широкие таблицы
  скроллятся внутри своего контейнера.

## 8. Движение

- Единственный easing — `--ease` из системы, длительность `--dur` .18s.
- Появление данных — `opacity 0→1` без сдвига по Y: в таблице сдвиг читается
  как перескок строки.
- Пульс статуса — `@keyframes pulse{0%,100%{opacity:1}50%{opacity:.3}}`,
  2–2.4s, из системы.
- Графики: линии отрисовываются сразу, без анимации пути; при обновлении
  данных — кроссфейд .18s.
- `prefers-reduced-motion` — переходы и пульс выключены, всё статично.
